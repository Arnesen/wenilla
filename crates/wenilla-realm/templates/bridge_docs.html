The JavaScript bridge

The game page exposes the running client to JavaScript as window.wenilla. A script can read everything the client knows — you, your target, every unit and object around you, your bags and quest log — and drive it: move, target, fight, loot, talk to NPCs, buy and sell, take and hand in quests, train. Everything goes through the client's own code paths, so a script can do exactly what you can do at the keyboard, nothing more.

Open the game, press F12 for the browser's console, and type wenilla.state.self. Everything below works from there, or from a script you load into the page.

Quick start

// Who and where am I?
wenilla.state.self                    // { name, level, health, pos: [x, y, z], facing, … }
wenilla.auto.nearest({ hostile: true, alive: true })   // the nearest enemy

// Kill it and loot it.
const mob = wenilla.auto.nearest({ hostile: true, alive: true });
await wenilla.auto.fight(mob);        // walks in, faces it, auto-attacks until it dies
await wenilla.auto.loot(mob);

// Sell junk at the nearest vendor, then repair.
await wenilla.auto.openVendor();
await wenilla.auto.sellJunk();
await wenilla.auto.repair();

// Hand in and pick up every quest at a quest giver.
await wenilla.auto.questGiver(wenilla.auto.nearest({ service: 'questgiver' }));

// Run the example leveling bot (or add ?bridge=grind to the page address).
const { grind } = await import('./examples/grind.js');
grind.start({ neutral: true });       // grind.stop() to end it

Bundled examples load with ?bridge=<name> in the address: hud (an overlay of nearby units), idle (a 30-line attack loop), grind (the leveling bot below). ?bridge=0 switches the bridge off for the session.

The state snapshot

wenilla.state is refreshed 20 times a second (wenilla.set({ hz }) to change it; wenilla.on('frame', s => …) to be called each time). Positions are WoW coordinates in yards — [x, y, z] with +X north, +Y west, +Z up, the numbers .go xyz uses. facing is radians counter-clockwise from north. Guids are hex strings.

{ session: { state: 'login' | 'charselect' | 'inworld', connected },
  map: { id },  zone: { id, name, subzone, minimapText, indoor, … },
  self:   Unit + { pos, facing, mounted, autoMove, casting, channeling },
  target: Unit | null,
  units:  [Unit …]   // everything within radius (60 yd), nearest first, at most 64
}

guid, kindIdentity; kind is 'player', 'unit' (creatures and NPCs), 'go' (game objects), 'corpse'.
name, level, entryName, level, and the creature or object template id (the same id databases list).
pos, distPosition, and distance from you in yards.
health, maxHealth, power, maxPower, powerTypePower type 0 mana, 1 rage, 3 energy.
hostile, friendly, reactionReaction 1–8 as the game colours it: 1–3 hostile (red), 4 neutral (yellow), 5–8 friendly.
dead, ghost, inCombat, targetGuidState; targetGuid is whom the unit is targeting (an enemy targeting you is on you).
servicesWhat an NPC offers: vendor, repair, trainer, questgiver, gossip, flightmaster, innkeeper, banker, auctioneer, spirithealer, battlemaster, stablemaster, …
questStatusThe mark over its head: 'available' (yellow !), 'reward' (yellow ?), 'incomplete' (grey ?), 'unavailable' (grey !), or null.
lootable, tapped, skinnableA body with loot for you; a mob someone else tagged; a skinnable body.
goType, goTypeName, lockedFor objects: chest (also herbs and veins, which are locked behind a gathering skill), mailbox, questgiver, goober, fishinghole, …; name is the object's own ('Peacebloom', 'Copper Vein').
moving, swimming, falling, standState, isPlayer, pvp, class, raceAs named.

self.autoMove is true while a walk started by moveTo is under way.

wenilla.auto — the automation library

Built on the commands above. Functions that take a unit accept a row from units or its guid; the ones that wait return promises and throw an Error saying what went wrong.

Finding things

units(filter) / nearest(filter)Units matching a filter, nearest first. A filter is a function or an object: { hostile, friendly, alive, dead, lootable, skinnable, tapped, inCombat, isPlayer, kind, name, entry, service, questStatus, goType, minLevel, maxLevel, maxDist, targetingMe, untargeted }. A name can be a RegExp.
find(unit)A unit's current row by guid.
attackers()Enemies attacking you.
me(), hp(), power()Your row; health and power as fractions 0–1.
await stats(){ level, xp, xpMax, money, hp, hpMax, mana, manaMax, inCombat } (money in copper).

Moving

await goto(pos, { tolerance })Walk there around walls and through doors: plans a path, walks it, replans when blocked.
await moveTo(pos, { tolerance })Walk there in a straight line; throws stuck if something is in the way.
await approach(unit, range)Get within range of a unit, following it if it moves.
face(unitOrPos)Turn to face it.
recordRoute({ spacing })Record waypoints while you walk; .stop() returns them.
await followRoute(points, { loop })Walk a recorded route.

Fighting

await fight(unit, { range, melee, rotation })Fight until it or you die: 'won', 'died' or 'lost'. rotation is an async function run every 300 ms with { cast, ready, cooldown, hasAura, target, me }.
await attack(unit) / target(unit) / clearTarget()Start auto-attack; select; deselect.
await cast(spell, onSelf)'Fireball' or 'Fireball(Rank 2)'.
await ready(spell) / cooldown(spell) / knows(spell)Known and off cooldown; seconds left; known at all.
await auras(token, debuffs) / hasAura(texture, token)Buff icons on a unit (1.12 names auras by icon).
await wenilla.auto.fight(mob, {
  rotation: async ({ ready, cast, me, target }) => {
    if (me.power >= 15 && await ready('Heroic Strike')) await cast('Heroic Strike');
    if (target.health / target.maxHealth < 0.2 && await ready('Execute')) await cast('Execute');
  },
});

Looting and bags

await loot(body) / gather(node) / skin(body)Open a body, or a herb, vein or chest, or skin a looted body, and take everything that fits.
await bags() / freeSlots()Every bag item { bag, slot, name, id, quality, count, link }; free slots.
await useItem(name)Use, eat, drink, open or equip a bag item.

NPCs

await open(service, npc)Walk to an NPC and open its window: vendor, trainer, flightmaster, banker, innkeeper, … (through its gossip menu if needed). Without npc, the nearest that offers it.
await openVendor() · wares() · buy(name, n) · sell(filter) · sellJunk() · repair() · closeVendor()Trade at the open vendor; sellJunk sells every grey item.
await openTrainer() · trainAll() · closeTrainer()Learn everything affordable.
await questGiver(npc, { accept, reward })Hand in what it takes and accept what it offers; reward(names) picks a reward index. Returns { accepted, completed }.
await questLog() · abandon(title)The quest log with objectives and completion.

Travel

await fly(destination)Book a flight from the nearest flight master to a known node whose name matches ('Stormwind', a RegExp).
await hearth()Use the Hearthstone.

Resting and dying

await rest({ hp, power, food, drink })Eat, drink or sit until above the thresholds.
await release() · corpseRun({ route })Release the spirit; run back from the graveyard and resurrect.

Navigation

The client never had pathfinding, so the bridge adds one: wenilla.path(pos) searches a one-yard grid through the collision the client has loaded around you — ground, buildings, walls, fences, trees — and answers waypoints that a body can walk, climbing stairs and going through doors. auto.goto uses it. It only knows what is loaded (a few hundred yards around you), so for a long trip record a route once with recordRoute and replay it with followRoute, or goto one leg at a time.

A leveling bot

examples/grind.js is a complete loop in about 200 lines: fight back when attacked, rest when low, loot bodies, sell and repair when the bags fill, visit quest givers it passes, run back after a death, otherwise pull the nearest fair fight within a leash of where it started. Copy it and adapt it — the rotation, the leash, the targets.

const { grind } = await import('./examples/grind.js');
grind.start({
  leash: 60,           // stay within 60 yards of where it started
  neutral: true,       // also fight yellow mobs
  food: 'Tough Jerky', // eat this when resting
  avoid: [/Elite/],    // never pull these
});
grind.stats             // { kills, deaths, looted, sold, quests }

Limits

  • A script runs in your browser tab, with your account, under the realm's rules. Ask the realm's admin what automation is welcome here.
  • Everything goes through the client: out of reach, out of range, on cooldown or not allowed is refused exactly as it would be for you.
  • Looting takes everything that fits (the game's auto-loot). The 1.12 client lets no script take single items, and a bind-on-pickup confirmation is up to you.
  • A hidden tab keeps running at a few frames a second (wenilla.set({ backgroundHz: 20 }) for more).
  • Pathfinding sees only loaded collision; water, steep slopes and long trips need routes.
